# Компьютерные сети — самостоятельная работа

**1.** Компьютерная сеть — это устройства, соединённые для обмена данными

**2.** Топологии: шина, звезда, кольцо

**3.** LAN — маленькая (дом, офис). WAN — большая (город, страна)

**4.** OSI — 7 уровней:
1. Физический
2. Канальный
3. Сетевой
4. Транспортный
5. Сеансовый
6. Представления
7. Прикладной

**5.** Коммутатор — L2; Маршрутизатор — L3

**6.** TCP/IP — 4 уровня:
1. Канальный
2. Межсетевой
3. Транспортный
4. Прикладной

**7.** Соответствие:
- Прикладной + Представления + Сеансовый = Прикладной
- Транспортный = Транспортный
- Сетевой = Межсетевой
- Канальный + Физический = Канальный

**8.** TCP

**9.** UDP

**10.** MAC-адрес — уникальный адрес устройства, L2

**11.** 48 бит = 6 байт. Записывается как: `00:1A:2B:3C:4D:5E`

## Часть E Практика

**28.** 172.16.0.0/16 - 500 хостов:
* для 500 хостов 2^9= 512; 512-2-510, значит нужно 9 бит
* 32-16-9=7 бит на подсети
- маска: /16+7 = /23 = `255.255.254.0`
- подсетей: 2^7 = 128
- первая: `172.16.0.0/23`
  - сеть: 172.16.0.0
  - 1-й хост: 172.16.0.1
  - последний: 172.16.1.254
  - broadcast: 172.16.1.255

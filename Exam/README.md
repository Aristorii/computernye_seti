# Экзамен по Компьютерным Сетям - Билет 9

## Тема: «Маршрутизация между сетями»

**Цель работы:** Построить сетевую топологию с несколькими подсетями, настроить маршрутизацию, NAT, базовые сетевые службы и проанализировать прохождение пакетов

### Задание и ход выполнения:

*   [x] **Топология:** Развернута сеть из 3 роутеров и 3 подсетей (по 2 ПК в каждой)
*   [x] **VLSM-планирование:** Рассчитаны маски и адресное пространство для экономии IP-адресов
*   [x] **Маршрутизация:** Настроены статические маршруты между роутерами. Проверена таблица маршрутизации
*   [x] **ARP:** Проверена работа протокола ARP на каждом сегменте сети
*   [x] **DHCP:** Настроены DHCP-серверы на каждом роутере для автоматической выдачи адресов ПК
*   [x] **NAT/PAT:** Настроен NAT (masquerade) на пограничном (крайнем) роутере для выхода во внешнюю сеть
*   [x] **DNS:** Поднят DNS-сервер в одной из подсетей для разрешения имен
*   [x] **Анализ TCP/UDP:** Выполнена команда `traceroute` до сервера и проанализированы используемые порты
*   [x] **Отчет:** Описание прохождения пакета и анализ таблиц маршрутизации

### Анализ прохождения пакета (Отчёт)

Пакет от компьютера PC2 к DNS-серверу с IP-адресом `192.168.1.2` проходит через несколько маршрутизаторов. Сначала он поступает на шлюз **Router2 (192.168.1.17)**, затем проходит через **Router1 (192.168.1.29)** и **Router0 (192.168.1.25)**

Путь определяется таблицами маршрутизации, в которых указаны сети назначения и следующие узлы передачи пакетов. Маршрутизаторы выбирают маршрут на основании наиболее подходящей записи в таблице маршрутизации. Для удалённых сетей в данной работе используются статические маршруты

Команда `tracert 192.168.1.2` позволила увидеть промежуточные узлы. При этом конечный адрес сервера в выводе не отобразился корректно, поэтому маршрут требует дополнительной проверки
